## Проблема

После этапов 2–5 публичный API изменился, а README, справочник, AGENTS, примеры и migration guide отставали.

## Решение

- Создан `docs/migration-v2.md`: типизированные `Update`, вложения/кнопки/разметка, таблицы переименований DTO и
  методов, удалённые поля, обёртки ответов, контакты/hash, порядок перехода.
- `README.md`: раздел истории v2.0.0, typed `Update`/вложения/разметка, новые имена методов и DTO, `Error`,
  `SimpleQueryResult`, `ChatPatch`, `ChatMembersList`, `ModifyMembersResult`, `UploadEndpoint`.
- `docs/api-reference.md`: § 1/3/4/7/8/9 — typed Update/Attachment/Button/Markup, `UploadEndpoint`, `Callback` без
  `message`, `User.name`, `MessageBody` без caption/format, `NewMessageLink` без chat, `VideoUrls` без mp4/preview,
  таблица `метод ↔ operationId` (15 отличий), удалённые `getChats`/`getUpdatesBatch`.
- `AGENTS.md`: контракты `Update`/`Attachment`/`Button`/`MarkupElement`, счётчики DTO 112/Enum 8, gotchas, ссылка на
  migration guide.
- `examples/`: `echo-handler` (instanceof), `send-media` (`PhotoAttachmentRequest`), `inline-keyboard`
  (Button/Keyboard),
  `verify-contact` (`ContactAttachment`, phone из `vcf_info`), `send-to-user` (typed sender/chat). PHP-lint примеров —
  OK.

## Тесты

PHP-код не менялся; Gate этапов 2–5 остаётся зелёным. Проверен `php -l` всех `examples/*.php` — ошибок нет.

## Нюансы

- В README остаются исторические разделы v1.x со старыми именами — это история версий, не текущий API.
- Остаточная строгость `Message.body`/`Callback.user`/`LinkedMessage.message`/`Subscription.time` отложена до
  расширенного смоука (решение 7 B).
- `docs/migration-v2.md` — обязательный файл релиза v2.0.0.
