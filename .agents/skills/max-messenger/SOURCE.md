Этот каталог — локальная копия для агентов проекта. Файлы `SKILL.md` и `references/` не редактируются; при обновлении
навыка их нужно заменить целиком. Каталог `.agents/` помечен `export-ignore` и не попадает в дистрибутив Packagist.

Рабочая копия для OpenCode — `~/.config/opencode/skills/max-messenger/` (из неё навык регистрируется с ID
`max-messenger`). Обе копии обновляются одной операцией: заменить каталог в `.agents/skills/` и скопировать его в
`~/.config/opencode/skills/`, затем обновить коммит выше.
